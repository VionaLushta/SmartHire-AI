## Release Scope

This release is documentation- and deployment-focused. It does not introduce new product behavior.

## Known Gaps

- Hosting provider credentials are not embedded in the repository.
- PostgreSQL must be provisioned in the target environment.
- SMTP and any external analytics credentials must be supplied by the deployment platform.
