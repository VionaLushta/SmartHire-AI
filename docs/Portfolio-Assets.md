# Portfolio Assets

## Professional Project Summary

SmartHire AI is a recruitment platform that combines a React frontend, FastAPI backend, PostgreSQL persistence, and AI-assisted workflows for hiring operations.

## Architecture Summary

- React 19 SPA with routed candidate, company, recruiter, and admin views.
- FastAPI service layer with thin route handlers.
- SQLAlchemy models, repositories, and Alembic migrations.
- File-based resume and report artifacts with controlled storage locations.
- Dedicated services for OCR, matching, ranking, scheduling, notifications, and analytics.

## Technology Stack

- React
- Vite
- Redux Toolkit
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL
- Pytest
- Vercel or Netlify for frontend hosting
- Render or Railway for backend hosting

## Key Achievements

- Authentication and role-based access control.
- Resume upload and parsing workflows.
- OCR and AI-assisted skill extraction.
- Candidate ranking and interview orchestration.
- Recruiter notes and notification handling.
- Analytics and Power BI export support.

## Business Value

- Speeds up recruiter review work.
- Improves hiring transparency and traceability.
- Reduces manual screening effort.
- Supports reporting and stakeholder communication.
