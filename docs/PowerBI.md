# Power BI Documentation

## Purpose

Power BI is used to visualize hiring, workflow, and analytics data extracted from SmartHire AI.

## Connection Options

Power BI can consume data from:

- CSV exports.
- JSON exports.
- PostgreSQL tables or views.

## Available Datasets

- Candidate pipeline data.
- Job posting summaries.
- Application status metrics.
- Resume matching results.
- Recruitment workflow events.
- Analytics snapshots.

## Suggested Dashboards

- Hiring funnel overview.
- Candidate source performance.
- Time-to-decision trends.
- Job market skill demand.
- Recruiter workload summary.

## Integration Notes

- Keep reporting data read-only.
- Avoid caching sensitive user-specific data in shared exports.
- Use the analytics service exports as the preferred handoff format for reporting workflows.
