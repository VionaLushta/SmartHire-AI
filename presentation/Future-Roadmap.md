# SmartHire AI Future Roadmap

## Version 2 Ideas

### 1. LLM Resume Analysis

- Add LLM-assisted resume summaries.
- Highlight strengths, risks, and candidate fit in plain language.

### 2. Interview Scheduling

- Allow recruiters to schedule interviews directly from the application record.

### 3. Calendar Integration

- Sync interview events with Google Calendar or Microsoft Calendar.

### 4. SMS Notifications

- Send time-sensitive application updates through SMS in addition to email.

### 5. AI Interview Assistant

- Provide guided interview questions based on the job description and candidate profile.

### 6. Multi-language CV Parsing

- Support more languages for candidate resumes and certificates.

### 7. Docker Deployment

- Add production-ready container packaging for backend and frontend services.

### 8. Cloud Storage

- Move uploads and generated reports to cloud object storage.

### 9. More Analytics

- Expand hiring funnel metrics, recruiter efficiency metrics, and skill trend dashboards.

### 10. Admin Automation

- Add additional admin tooling for audits, workflows, and reporting exports.

## Prioritization

1. Interview scheduling and calendar integration.
2. Cloud storage and Docker deployment.
3. LLM resume analysis.
4. Multi-language parsing.
5. SMS notifications.
