# SmartHire AI Screenshots Guide

## Purpose

Capture a clean, consistent set of screenshots for GitHub, portfolio, internship evaluation, and interview use.

## Recommended Checklist

- Landing Page
- Candidate Registration
- Candidate Login
- Candidate Dashboard
- Candidate Profile
- Resume Upload
- Company Dashboard
- Recruiter Workspace
- Admin Dashboard
- Analytics Dashboard
- Power BI Dashboard
- Error or empty state example

## Capture Guidelines

- Use a consistent browser size.
- Capture clean states with visible labels and charts.
- Avoid personal or sensitive data in screenshots.
- Prefer logged-in state screenshots for dashboards.
- Include one example of loading or empty state if it helps explain the UX.

## Suggested Order

1. Landing page.
2. Candidate flow.
3. Recruiter flow.
4. Admin flow.
5. Analytics and reporting.
